## Description (copy-paste)

The first time I ran this live, I left out the return date. The agent didn't guess and search anyway — it stopped and asked.

I'm a product designer building an AI flight-booking agent (FlightGenie) in public, and this is the moment that mattered most: a gap I hadn't specifically built for, resolved by the same escalation surface that already exists for booking approvals. Not a new fallback — the mechanism doing exactly the job it was designed for.

Why it matters: a wrong assumption about a return date isn't a minor UX rough edge — it's a wrong ticket. I'd rather a chat interface stop and ask than quietly resolve ambiguity in whatever direction is easiest to code.
