This is FlightGenie's automated mode. Search uses live fares. Every booking is simulated.

I describe a round trip, nonstop, under six-fifty, with departure and arrival preferences.

The plan states when the agent can proceed and when it needs approval.

The request leaves out the return date.

The agent asks for clarification. Automatic booking permission does not resolve missing trip information.

I clarify the dates, and the agent searches.

This take returned two hundred thirty-seven offers. Code checks the configured budget, stops, and total duration.

I can inspect eligible offers, options within the budget tolerance, and rejected results. The cards show the classification reasons.
